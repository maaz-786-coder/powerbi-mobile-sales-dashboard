# powerbi-mobile-sales-dashboard
📱 Mobile Sales Analysis Dashboard | Power BI

📌 Project Overview

This project focuses on analysing mobile sales data using Microsoft Power BI to identify sales trends, customer purchasing behaviour, payment preferences and business performance.

I developed an interactive dashboard that transforms raw sales data into meaningful business insights through data visualisation, KPIs and interactive filters.

The dashboard helps businesses monitor performance, compare mobile brands and models, and understand customer behaviour.

🎯 Project Objectives

Analyse overall mobile sales performance.

Identify top-performing mobile brands and models.

Understand customer payment preferences.

Analyse sales distribution across different cities.

Track daily and monthly sales trends.

Evaluate customer ratings.

Build an interactive dashboard for business decision-making.

🛠️ Tools & Technologies

Microsoft Power BI – Dashboard development and data visualisation.

Power Query – Data cleaning and transformation.

DAX – Calculations and measures.

Excel – Source dataset.
